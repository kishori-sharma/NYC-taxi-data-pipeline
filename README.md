
# NYC Taxi Data Pipeline

## Project Overview

This project demonstrates a data pipeline for processing and analyzing NYC Taxi trip data using Databricks.

## Technologies Used

* Python
* Apache Spark / PySpark
* Databricks
* SQL
* Data Engineering

## Project Workflow

1. Load NYC Taxi dataset into Databricks.
2. Clean and transform the raw data.
3. Perform data processing using PySpark.
4. Analyze the processed data using SQL.
5. Prepare the data for further analysis and reporting.

## Key Features

* Data ingestion and processing
* Data cleaning and transformation
* PySpark-based data pipeline
* SQL-based data analysis
* Cloud-based development using Databricks

## Project Purpose

The purpose of this project is to understand the fundamentals of building a data pipeline and working with large datasets using Databricks and PySpark.
